# pmlegal

PawMate 의 **법무 문서 정본** 저장소. 앱(`pmdart`)이 `assets/terms/` 로 번들하는
문서의 원본이 여기 있고, 두 곳은 항상 바이트 단위로 같아야 한다.

| 파일 | 앱 에셋 | 성격 |
|---|---|---|
| `02위치기반서비스이용약관.md` | `location_terms.md` | 서비스 내 게시 + 방통위 신고 첨부 |
| `03개인정보처리방침.md` | `privacy_policy.md` | 법정 상시 게시 (개인정보보호법 §30) |
| `04서비스이용약관.md` | `terms_of_service.md` | 서비스 내 게시 |
| `07간이후기이용조건.md` | `lite_review_terms.md` | 간이 후기 이용 시 동의 |

운영 문서: `00주의사항.md` · `05신고준비체크리스트.md` · `06운영점검주기.md`

## 01 이 없는 이유

`01사업계획서초안.md`(위치기반서비스 신고 첨부용)은 **이 저장소에서 관리하지 않는다.**

이 저장소는 공개인데 그 문서에는 게시 의무가 없는 개인사업자 신원 정보 — 대표 개인
휴대전화번호, 사업장 주소(자택 겸용), 사업자등록번호 — 가 들어 있다. 나머지 문서는
법정 게시 의무가 있어 공개가 맞지만 01 은 방통위 제출용이라 공개할 이유가 없다.

2026-08-04 에 이력에서 제거하고 로컬 전용으로 돌렸다(`.gitignore`). 파일은 작업
디렉터리에 그대로 있으므로 신고·갱신 때 그대로 쓰면 된다.

⚠️ **그 파일의 백업은 이 저장소가 대신해 주지 않는다.** 로컬에만 있으므로 별도로
챙겨야 한다.

## 문서를 고칠 때

정본만 고치면 **이용자가 보는 문서는 그대로 옛 내용**이다 — 앱의 약관 링크가 전부
번들 에셋이고 원격 URL 을 쓰지 않기 때문이다. 정본 개정과 `pmdart` 에셋 동기화를
한 세트로 진행하고, 시행일은 각 문서의 개정 연혁 조항에 남긴다.

**공고 일자는 실제로 공지를 올린 경우에만 적는다.** 정식 출시 전(제3자 이용자 없음)
개정에는 사전 공지 대상이 없어 공고 문구를 쓰지 않는다 — 안 한 일을 했다고 적으면
공개 저장소와 앱 양쪽에 사실이 아닌 기재가 남는다. 출시 이후에는 공지를 먼저 올리고
그 날짜를 적는다.

(연혁: 사업자등록 → 소상공인 위치기반서비스 신고(1인 창조기업) 준비로 시작한 저장소다.)
